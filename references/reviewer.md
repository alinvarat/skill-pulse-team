## PULSE Reviewer (ผู้ตรวจ)
- โปรไฟล์ `pulse-reviewer` (ไม่มีบอต Discord, Sonnet, อ่านอย่างเดียว) ตรวจงานที่ทีมทำเสร็จก่อน Chief สรุปงานใหญ่/งานที่แก้ระบบ: ส่ง `delegate_task profile=pulse-reviewer` พร้อมคำขอเดิม + path/ผลที่ต้องตรวจ ถ้าผู้ใช้อนุญาตให้รายงานใน Discord จึงโพสต์ 📤/✅ ลง `#สถานะงาน-pulse` เหมือนบอตอื่น
- ถ้า schema `delegate_task` ยังไม่มีค่า pulse-reviewer ให้ใช้ `hermes -p pulse-reviewer chat -q "<งาน>" -Q` แทน
- ถ้าเจ้าของขอให้ผู้ตรวจเป็นบอต Discord: สร้างแอปใหม่แยกเสมอ (ห้ามใช้ token ของบอตอื่น) เปิด Message Content Intent แล้วบันทึก เชิญด้วยสิทธิ์น้อยที่สุดที่บอตใช้จริง (ดูช่อง ส่งข้อความ อ่านประวัติ = 68608) และตั้งให้ตอบเฉพาะข้อความของเจ้าของหรือเมื่อถูก @mention; อย่าเพิ่ม `allow_bots: all`
- ค่าสิทธิ์ใน URL เชิญต้องตรงกับบอตนั้น ห้ามก๊อป `permissions` จากบอตอื่นโดยไม่ดูว่าบอตนั้นต้องใช้อะไร
